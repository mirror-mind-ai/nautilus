# Nautilus Family

The Nautilus Family gathers the bodies that allow the method to exist as human language, formal declaration, Mirror Mind adaptation, and dedicated practice experience.

The family is not a collection of independent projects. It exists to preserve coherence between what the method means, what the protocol declares, what Mirror can operate, and what the [Participant](participant.md) experiences in the Harness.

## Components

| Component | Function |
| --- | --- |
| Nautilus Agentic Method | Conceptual and pedagogical layer, oriented to understanding and practicing the method |
| Nautilus Agentic Protocol | Formal, portable, and verifiable declaration of the Nautilus grammar |
| Nautilus Mirror Extension | Adapter and reference implementation of the Nautilus grammar inside Mirror Mind |
| Nautilus Harness | Dedicated application for the practical experience of the Nautilus grammar |

## Nautilus Agentic Method

The Method gives language, meaning, and human criteria to practice.

It explains what [Value Generation](value-generation.md), a Journey, a Mission, a Delivery, Evidence, a [Realization](realization.md), [Impact](impact.md), and an Integration mean for whoever uses Nautilus.

Its function is to prevent the family from becoming merely technical. Before declaring or implementing a form, the method needs to make it understandable and practicable.

## Nautilus Agentic Protocol

The Protocol translates the Method language into declarative form.

It defines fields, versions, compatibility, and recognizable structures. Its function is to allow the grammar to be portable, validatable, and shareable across implementations.

## Nautilus Mirror Extension

The Mirror Extension adapts Nautilus to the Mirror Mind runtime.

It is the reference implementation inside Mirror, connecting the Nautilus grammar to journeys, memory, modes, commands, surfaces, and practices of the Mirror ecosystem.

## Nautilus Harness

The Harness is the dedicated application for practice.

It turns the Nautilus grammar into direct experience for human and agentic Participants. It is where the method language should appear as living conduction, not abstract documentation.

## Coherence between components

Each component speaks in a different register, but all must recognize the same form.

If the Method names a concept, the Protocol must be able to declare it when it becomes formal. If the Protocol requires a field, the Method must justify its human meaning. If the Mirror Extension operates a behavior, it must exist in the grammar. If the Harness uses an experiential metaphor, it must not replace the common ontology.

This coherence is how the family grows without losing form.
