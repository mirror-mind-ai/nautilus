# Realization Cycle

The Realization Cycle describes the arc through which the Nautilus grammar conducts Value Generation.

In the current version, only Mission formulation is stabilized. The complete cycle appears as a conceptual map for orienting the next chambers.

## Conceptual arc

```text
Value Generation
  happens in the Human Territory
    which hosts Journeys
    crossed by Participants
      who formulate Missions
        that orient Deliveries
          that produce Evidence
            that sustains Realizations
              that may generate Impact
                which informs Integration
                  which preserves form for the next chamber
                  which returns to the Human Territory with more capacity to realize
```

This arc involves [Value Generation](value-generation.md), [Human Territory](human-territory.md), [Journey](journey.md), [Participants](participant.md), [Mission](mission.md), [Delivery](delivery.md), [Evidence](evidence.md), [Realization](realization.md), [Impact](impact.md), and [Integration](integration.md) as connected concepts.

## Formulation

Formulation is the phase in which an intention of value gains minimal form.

It answers what is being named, why it matters now, and whether it still remains before execution.

Current artifact: Mission with `id`, `title`, `purpose`, and `status: formulated`.

## Execution

Execution is not yet specified in this version.

It will be the passage from formulated Mission to oriented work. When it enters, it will need to treat Role, Authority, responsibility, context, and limits of human and agentic action.

## Delivery

[Delivery](delivery.md) will be the produced result or change effected by the Mission as a candidate carrier of value.

The method should distinguish Delivery types without forcing everything to become a file or completed task.

## Evidence

[Evidence](evidence.md) will be the support of recognition.

It should answer how the Delivery can be observed, verified, or witnessed proportionally.

## Realization

[Realization](realization.md) will be the recognition that value touched the [Human Territory](human-territory.md) and became available in the world of the [Journey](journey.md).

It will require relation between Mission, Delivery, and Evidence.

## Impact

[Impact](impact.md) will be what happens after realized value becomes available in the Human Territory.

It may be measured qualitatively and quantitatively, but it will not be controlled in the same way as Realization.

## Integration

[Integration](integration.md) will be the preservation of learning in the next form.

It may update memory, language, decision, practice, pattern, or next Mission.

## Why the cycle is not yet a state machine

The cycle should not become a state machine too early.

Its current function is to orient thinking and documentation. Formal states enter only when there is operational need and recognition by the Nautilus components.
