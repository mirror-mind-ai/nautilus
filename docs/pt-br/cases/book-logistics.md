# Caso canônico: logística dos livros

## Tipo

Prospectivo.

## Função do caso

Formular uma [Missão](../method/mission.md) viva antes de executar.

Este caso testa se Nautilus ajuda a nomear uma intenção prática sem transformar cedo demais a formulação em plano, tarefa ou execução.

## Estado

Rascunho canônico. Precisa ser preenchido com a situação concreta da logística dos livros.

## [Jornada](../method/journey.md)

A definir.

## [Participantes](../method/participant.md)

A definir.

## Missão formulada

```yaml
mission:
  id: mission-book-logistics
  title: Organize book logistics
  purpose: Give form to the movement required to deliver or coordinate books without hiding execution inside the formulation.
  status: formulated
```

## Teste de Inteireza

| Pergunta | Resposta atual |
| --- | --- |
| Que intenção dirigida está sendo nomeada? | Organizar a logística dos livros |
| Por que essa intenção importa agora? | Porque há uma [entrega](../method/delivery.md) prática que precisa ganhar forma antes da ação |
| A Missão continua em formulação, sem execução escondida? | Parcialmente. A descrição precisa ser revisada para não antecipar plano |
| Os quatro corpos reconhecem os mesmos campos? | Sim, para a Missão mínima |
