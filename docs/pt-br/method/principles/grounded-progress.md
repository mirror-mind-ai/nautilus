# Avanço Sustentado

Uma Jornada só deve reconhecer avanço quando houver lastro suficiente de que valor foi tornado disponível, transformado ou aprendido no Território Humano.

Este princípio protege a Jornada de confundir atividade, intenção, volume ou impressão subjetiva com progresso. Evidência é o mecanismo do Avanço Sustentado.

Veja também [Evidência](../evidence.md) e [Princípios](../principles.md).
