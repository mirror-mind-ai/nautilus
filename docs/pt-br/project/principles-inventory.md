# Inventário de Princípios

Este inventário acompanha princípios candidatos de Nautilus antes que eles se tornem páginas publicadas do método.

## Estados

| Estado | Sentido |
| --- | --- |
| A avaliar | Princípio candidato identificado, mas ainda não avaliado conceitualmente |
| Em avaliação | Princípio em discussão conceitual ativa |
| Estratégia definida | Princípio tem estratégia clara de documentação, mas ainda não foi publicado |
| A publicar | Princípio pronto para trabalho de documentação |

## Inventário

| Princípio | Estado | Notas |
| --- | --- | --- |
| Continuidade Confiável | Estratégia definida | Usar `reliable-continuity.md` como página do princípio. Frase canônica: cada giro da Jornada deve preservar forma suficiente para que o próximo comece com mais capacidade, não com reconstrução. |
| Valor como Direção | Estratégia definida | Usar `value-generation.md` como página do princípio. Posicioná-lo antes de Continuidade Confiável em `principles.md`, porque ele dá direção enquanto a continuidade preserva forma ao longo do tempo. Frase canônica: toda Jornada deve orientar sua Realização pelo valor que busca tornar disponível no Território Humano. |
| Avanço Sustentado | Estratégia definida | Usar `evidence.md` como página do princípio. Evidência se torna o mecanismo, não o nome do princípio. Posicioná-lo depois de Valor como Direção, porque valor dá direção e Avanço Sustentado protege o reconhecimento de virar impressão subjetiva ou narrativa sem lastro. Frase canônica: uma Jornada só deve reconhecer avanço quando houver lastro suficiente de que valor foi tornado disponível, transformado ou aprendido no Território Humano. |
| Expansão Integrada | Estratégia definida | Usar `integration.md` como página do princípio. Integração se torna o mecanismo, não o nome do princípio. Posicioná-lo depois de Continuidade Confiável, porque a continuidade preserva forma e Expansão Integrada nomeia o ganho de capacidade que deve seguir cada Realização. Frase canônica: cada Realização deve expandir a capacidade da Jornada sem romper a forma que permite continuar. |
| Centralidade do Território Humano | A avaliar | Princípio candidato derivado de Território Humano. Precisa relação com valor e impacto. |
| Colaboração Humano-Agêntica | A avaliar | Princípio candidato derivado da definição do método. Precisa fronteiras de autoridade e responsabilidade. |
| Crescer sem Perder a Forma | Estratégia definida | Tratar como princípio fundador guarda-chuva em `principles.md`, não como página conceitual separada por enquanto. Ele dá unidade aos outros princípios: Valor como Direção, Avanço Sustentado, Continuidade Confiável e Expansão Integrada. Frase canônica: cada avanço deve ampliar a capacidade da Jornada preservando a coerência que permite continuar. |
| Proporcionalidade Formal | A avaliar | Princípio candidato derivado de minimalidade e câmaras semânticas. Precisa distinção em relação a Evidência Proporcional. |
