# Principles Inventory

This inventory tracks candidate Nautilus principles before they become published method pages.

## States

| State | Meaning |
| --- | --- |
| To evaluate | Candidate principle identified, but not yet conceptually assessed |
| In evaluation | Principle is under active conceptual discussion |
| Strategy defined | Principle has a clear documentation strategy, but is not yet published |
| To publish | Principle is ready for documentation work |

| --- | --- | --- |
