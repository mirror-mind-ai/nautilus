# DS-002, Define Value Lenses and Lean Influence

**Status:** 🔵 Pulled

---

## Outcome

Nautilus documentation distinguishes value lenses rather than value stages: a pragmatic lens, connected to Lean value and market recognition, and an integrative lens, centered on the integration of the Human Territory. The method can speak to pragmatic audiences without reducing value to what customers pay for.
