# Canonical cases

Canonical cases exist to press the Nautilus grammar against real situations.

They are not decorative examples. They help perceive whether the language simplifies work, reveals gaps, and preserves recognizability between Method, Protocol, Mirror Extension, and Harness.

## Initial cases

| Case | Type | Function |
| --- | --- | --- |
| [Assessment retry](retry-assessment.md) | Retrospective | Reconstruct an already occurred realization to test whether the grammar recognizes intention, delivery, and evidence |
| [Book logistics](book-logistics.md) | Prospective | Formulate a living Mission before execution, testing the Integrity Test |

## How to read the cases

Each case should record:

- involved Journey;
- known Participants;
- formulated Mission;
- expected or observed Delivery;
- available or necessary Evidence;
- recognized or desired Realization;
- possible Integration;
- gaps revealed by the grammar.

At this stage, cases may contain fields not yet formalized. When this happens, the case should mark the gap instead of pretending the current version already solves it.
